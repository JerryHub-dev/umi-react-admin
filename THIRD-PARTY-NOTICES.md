## Dependency security remediation (2026-10-09)

Historical accepted-without-fix entries have been converted to source-level handling; the full build and runtime chains are audited, and `auditConfig.ignoreGhsas` is no longer configured. Advisories match by version number while local patches keep the real versions; non-zero raw audit results must be recorded separately from patch proofs.

| Component / original risk | Handling |
| --- | --- |
| image-size / less | Kept the less >=4.9.1 override; removed the legacy image-size path |
| react-router / react-router-dom 6.30.4 | Umi's 6.x path upgraded to 7.18.2; patched the StaticRouter import and an alias matching full entries only, keeping Router 7 subpath exports; unused legacy test tooling removed |
| uuid 8.3.2 | ExcelJS's dependency upgraded to 11.1.1, which still supports CommonJS |
| postcss-selector-parser 6.1.3 | Both legacy major paths upgraded to 7.1.6, including the newer advisory fixes |
| decode-uri-component 0.2.2 | Forward-ported the official linear-decoding fix, keeping the CommonJS API that query-string needs; the real source patch lives in patches/ |
| braces 3.0.3 | Local source adds parsing/AST/compile depth, node-count, expansion-count and output budgets that range limits cannot bypass; real-package attack regressions verify both plain globs and boundary rejections |
| elliptic / crypto-browserify | Removed the generic browser crypto polyfill chain; ExcelJS uses the bare entry with only the hash/randombytes actually needed, avoiding the prebundled legacy ECC copy. Real SHA-512 worksheet protection is retained |
| sprintf-js 1.0.3 | Removed the unused Umi lint/test tool path; the template continues to use standalone ESLint/Vitest |

Local patches use pnpm `patchedDependencies` and are pinned by the lockfile. `pnpm audit:security` prints the full raw advisories; a known advisory is only considered fixed when every installed instance matches the patched source exactly and passes real attack regressions — everything else fails. Audit records must not be read as "upstream has shipped a fix".

Patch upgrades require re-verifying source hashes, CommonJS/browser entries, build and E2E, followed by updated proofs; simply deleting a patch or adding an ignore is not acceptable. Official advisories: [braces](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm), [decode-uri-component](https://github.com/advisories/GHSA-vcc3-ghjq-m6fr), [follow-up React Router 7 fixes](https://github.com/advisories/GHSA-qwww-vcr4-c8h2).
